## 2. Konsep Kreatif Website

**Big Idea:** "Ikut menyelam ke dalam kenangan Loka" — pengalaman scroll di website dibuat seperti proses *dive* (menyelam ke pikiran) di dalam game: transisi antar section terasa seperti berpindah dari dunia nyata (siang, warm tone, tenang) ke dunia batin/surreal (malam, starry, glowing).

**Mood:** nostalgia 90-an, malam berbintang, pixel art hangat, sedikit misterius tapi tetap "slice of life" — bukan horor.

**Do's**
- Buat ilustrasi/pixel art **orisinal** terinspirasi gaya game (bukan re-trace aset asli).
- Gunakan tone warna, tipografi, dan animasi untuk membangun suasana, bukan meniru layout situs resmi.
- Sertakan disclaimer kecil di footer: *"Website ini adalah proyek fan-made untuk kompetisi, dibuat oleh [nama tim], bukan situs resmi. Semua hak game A Space for the Unbound dimiliki oleh Mojiken Studio & Toge Productions."*

**Don'ts (wajib dihindari sesuai Juknis D.5 & D.11)**
- Jangan gunakan template premium/jadi secara utuh.
- Jangan copy-paste screenshot resmi dalam jumlah besar sebagai aset desain utama (boleh menyematkan **1 trailer resmi via embed YouTube** karena itu bukan "penyalinan aset", tapi hindari mengunduh & mengedit ulang artwork resmi tanpa kredit).
- Jangan gunakan CMS (WordPress, Wix, dll).

## 4. Rekomendasi Tech Stack (Semua Gratis)

**Opsi A — Direkomendasikan untuk "vibe coding" cepat & rapi:**
- Next.js (React) + Tailwind CSS + Framer Motion (animasi) + Lenis/Locomotive Scroll (smooth scroll)
- Deploy: Vercel (gratis)

**Opsi B — Lebih ringan, cocok jika tim kurang familiar React:**
- HTML + Tailwind CSS (via CDN atau build) + GSAP + ScrollTrigger + AOS (Animate On Scroll)
- Deploy: Netlify / GitHub Pages (gratis)

Kedua opsi 100% memakai tools open-source/free-tier, sesuai Juknis D.3 dan D.4.
